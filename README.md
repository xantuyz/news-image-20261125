One image summing up the world's news of Wednesday, 25 November 2026: the
Shenzhou-24 launch carrying Muhammad Zeeshan Ali, the first Pakistani in
orbit, bound for Tiangong; Australia's October CPI running hot at 4.9%;
Asian stocks sliding on a fresh US tariff threat; storms threatening
Thanksgiving travel in the US; a remote M5.9 quake in the Southern Ocean;
and US inflation and growth data due later in the day. Drawn with Pillow at
build time (`render.py`); the submitted program (`main.py`, standard library
only) copies the pre-rendered `entry.png` to the output directory and
verifies its SHA-256, so both grader runs write byte-identical files.
